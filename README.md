# 🛒 Flipkart UI Clone – Pure HTML & CSS  

> _“A clean and responsive Flipkart-inspired shopping UI built only with HTML and CSS.”_

This project is a **frontend-only clone** of Flipkart’s UI created with **pure HTML and CSS**.  
It replicates Flipkart’s homepage structure, product grids, navigation bar, and responsive layout to practice core web development skills.

---

## ✨ Features

- **Homepage Layout** – Header, navigation, product sections  
- **Hero Banners** – Promotional banners and sliders (CSS-based)  
- **Product Grids** – Clean cards for products with hover effects  
- **Navigation Bar** – Logo, search bar, and category links  
- **Footer Section** – Links, social media, and credits  
- **Responsive Design** – Mobile-first layout with CSS Flexbox/Grid  
- **Pure HTML & CSS** – No frameworks or JavaScript  

---

## 🏗️ Tech Stack

- **HTML5** – Semantic markup  
- **CSS3** – Flexbox, Grid, Media Queries, Transitions  
- (Optional) CSS Variables for colors and fonts
